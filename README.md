# Logica-programacion-3

Aplicación web sencilla que calcula y muestra en tiempo real el factorial de un número ingresado por el usuario.

[Click acá para ver demo](https://maralvgen.github.io/logica-programacion-3/) 🌐

## Características
- Cálculo instantáneo al ingresar o modificar el valor.
- Validación de entradas para enteros no negativos.
- Interfaz liviana y responsive.
